# EduQuest

## Description

EduQuest is an AI-powered Gamified Learning Management System developed for the thesis:

"The Gamification on Student Engagement Among High School Students"

The system increases student engagement through:

- Interactive learning
- Quizzes
- XP
- Levels
- Badges
- Medals
- Certificates
- Leaderboards
- AI-generated quizzes
- AI educational games
